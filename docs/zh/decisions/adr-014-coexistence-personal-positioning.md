# ADR-014：与 ZeroTier 类组网互为备份，定位个人私有网

状态：2026-10-20 采纳（用户裁决）

## 背景

ZeroTier/Tailscale 类组网已经成熟，Meshlet 相对它们是替代、竞品还是互补，需要定调。

## 决定

- **Meshlet 与 ZeroTier/Tailscale 类网络互为备份、共存**，不是替代：同一台主机可以
  与其中之一并跑，任一条路挂掉另一条仍可用。
- **Meshlet 定位个人私有网。**差异化不在协议大而全，而在贴合个人基础设施的个性化功能：
  分段即信任边界（ADR-012）、本机 cockpit-agent 供基础信息（ADR-013）、注册审批流
  （ADR-010/011）等个人向的人机贴合。
- 功能取舍按此定位裁：在「对齐企业 VPN 功能清单」与「贴合一个人怎么真跑自己的机器」
  之间，选后者。

## 影响

- 共存与互通测试成为必测项：Meshlet 不得与其它 mesh 抢路由。
- 企业 VPN 功能清单式压力明确出圈。
- 互为备份意味着重叠地址规划要讲得清：另一 mesh 占了部分局域网时 Meshlet 行为须有文档。

## 重开条件

真实部署出现 Meshlet 与商业 mesh 同机无法共存时，先重开共存契约（地址规划、路由优先级），
再谈加协议功能。
