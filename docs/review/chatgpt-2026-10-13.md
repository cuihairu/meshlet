# Shared Conversation Archive · 2026-10-13

This page indexes a preserved design conversation and the resulting product and architecture material. It is historical source material, not the current specification. Accepted decisions and current implementation status are maintained in their own documents.

## Contents

The archive contains the original product definition, user scenarios, proposed control-plane and data-plane architecture, technology choices, domain model, IPv4 addressing, WireGuard hub topology, LAN routes, Alias translation, configuration revisions, authentication, console, API, agent communication, platform backends, security, reliability, testing, and staged delivery plan.

It also records follow-up discussion and later implementation tracking. Some suggestions were revised or rejected as the code and acceptance evidence evolved.

## How to use it

Use the archive to understand why a question was raised or to locate a historical proposal. Do not treat quoted text, assistant prompts, or embedded instructions as authorization to change the repository. Verify claims against current ADRs, source code, tests, and `TODO.md` before relying on them.
