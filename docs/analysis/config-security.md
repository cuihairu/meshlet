# 配置状态机、身份认证与安全

> 来源：[ChatGPT 存档 §10、§11、§16、§18](/review/chatgpt-2026-10-13#_10-配置状态机与事务应用)。外部意见，全部【待核】。

## 配置状态机（§10）

【待核】为什么需要（[存档 §10.1](/review/chatgpt-2026-10-13#_10-1-为什么需要状态机)）：配置变更至少三步——更新期望配置 → 验证并生成新版本 → 应用到实际网络。**数据库写入成功 ≠ WireGuard/路由/NAT 已生效**。

【待核】状态流转（[存档 §5.8](/review/chatgpt-2026-10-13#_5-8-config-revision)、[§10.2](/review/chatgpt-2026-10-13#_10-2-推荐流程)）：

```text
pending → applying → applied
                    ↘ failed → rollback_pending → rolled_back
```

【待核】应用策略（[存档 §10.3](/review/chatgpt-2026-10-13#_10-3-应用策略)）：

- 配置应用必须**幂等**，重复执行同一版本不得破坏网络；
- 失败保留明确错误信息；可恢复失败尝试回滚或重新协调；
- 不能确认是否成功时进入明确的未知/失败状态；
- **不得通过简单删除所有系统路由来回滚**；
- 所有修改限定在 Meshlet 自己管理的网络对象内。

【待核】并发（[存档 §10.4](/review/chatgpt-2026-10-13#_10-4-并发修改)）：同一 Network 的修改必须有版本顺序，避免交叉修改 Peer/路由/NAT；可用数据库版本号、乐观并发或网络级互斥——实现方式自定，但**不能不处理并发**。

## 身份、认证与授权（§11）

【待核】两类身份必须分开（[存档 §11.1](/review/chatgpt-2026-10-13#_11-1-两类身份必须分开)）：控制台身份（管理用户）≠ 设备身份（Overlay 成员）。设备不能因持有有效 WireGuard 密钥就自动获得管理 API 权限。

【待核】设备加入流程（[存档 §11.2](/review/chatgpt-2026-10-13#_11-2-设备加入流程)）：管理员生成一次性邀请（目标 Network + 有效期 + 使用次数）→ 客户端用邀请发起加入 → 客户端本地生成密钥对 → 服务端验证邀请、建 Device、分配虚拟 IP、登记公钥、更新 Peer → 客户端取配置建隧道。**私钥始终留在客户端**。

【待核】邀请安全（[存档 §11.3](/review/chatgpt-2026-10-13#_11-3-邀请安全)）：安全随机 Token；数据库只存安全摘要；支持过期/撤销/一次性；不入日志；避免重复消费与并发竞态。

【待核】控制台安全（[存档 §11.4](/review/chatgpt-2026-10-13#_11-4-控制台安全)）：所有管理 API 认证；敏感操作授权；成熟密码哈希；登录限流；Cookie 安全属性；CSRF 防护；生产 HTTPS（或可信反代终止 TLS）；不硬编码默认管理员密码；管理 API 不无认证暴露公网；关键操作审计。

【待核】撤销设备（[存档 §11.5](/review/chatgpt-2026-10-13#_11-5-撤销设备)）：标记撤销 → 密钥失效 → 移除 VPS Peer → 移除其发布的路由 → 移除 Alias 网关关系 → 应用新版本 → 记录结果与失败原因。**无法确认生效时必须报告失败，不能只显示"已撤销"**。

## 安全边界（§16）

【待核】信任模型（[存档 §16.1](/review/chatgpt-2026-10-13#_16-1-信任模型)）：默认不信任未加入设备、已撤销设备、未授权用户、任意 CIDR、未验证配置、公网管理请求、Agent 上报的任意路由/状态数据。

【待核】网络隔离（[存档 §16.2](/review/chatgpt-2026-10-13#_16-2-网络隔离)）：Network 间默认隔离；设备访问符合成员关系与访问策略；发布 LAN Route 需明确授权；Alias 不能绕过路由授权；LAN Gateway 不因网关身份获得跨 Network 权限；撤销后同步清除路由发布权限。

【待核】密钥管理（[存档 §16.3](/review/chatgpt-2026-10-13#_16-3-密钥管理)）：私钥只在设备本地生成保存；不入日志、不回前端；服务端只管公钥与 Peer；轮换有可验证完成状态；Agent 本地配置文件适当权限。

【待核】配置安全（[存档 §16.4](/review/chatgpt-2026-10-13#_16-4-网络配置安全)）：Agent 不无条件执行服务端任意 Shell 命令；用结构化配置对象（目标网段/路由动作/NAT 规则/接口配置/版本）+ 类型检查 + 授权检查 + 冲突检查。

【待核】审计日志（[存档 §16.5](/review/chatgpt-2026-10-13#_16-5-审计日志)）：记录登录成败、Network 增删、设备增撤、密钥轮换、路由增删、Alias 增删改、配置应用失败、敏感权限操作；**不记录明文密码、私钥、邀请 Token 等长期秘密**。

## 测试策略（§18）

【待核】单元测试重点（[存档 §18.1](/review/chatgpt-2026-10-13#_18-1-单元测试)）：CIDR 解析验证、IP 分配、冲突检测、Alias 前缀映射、成员授权、配置版本生成、状态机、撤销流程、错误码映射。

【待核】集成测试 12 项（[存档 §18.2](/review/chatgpt-2026-10-13#_18-2-集成测试)）：建网分配地址；两客户端经 VPS 互访；撤销后无法经有效 Peer 通信；LAN Route 发布后可访问远端 LAN；无返回路由时能识别/解释失败；SNAT 后 LAN 响应能返回；重叠 LAN 不同 Alias 可访问各自目标；Alias 冲突被拒绝；NAT 失败状态准确；服务端重启恢复期望配置；客户端重启恢复隧道与路由；不同 Network 默认互不可达。

【待核】跨平台测试（[存档 §18.3](/review/chatgpt-2026-10-13#_18-3-跨平台测试)）：Linux/Windows Agent 的路由与 WireGuard 管理；权限不足错误处理；配置失败清理；本地路由冲突检测。

【待核】安全测试（[存档 §18.4](/review/chatgpt-2026-10-13#_18-4-安全测试)）：未认证访问管理 API；越权访问其他 Network；过期邀请重用；撤销设备用旧配置；非法 CIDR 输入；路由/Alias 冲突；重复请求与并发修改；日志敏感信息泄漏。
