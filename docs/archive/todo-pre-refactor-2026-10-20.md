# Meshlet TODO

The current requirements are bounded by personal self-hosting: multiple devices, grouping within a network, controlled port forwarding, and HTTP service routing. A static review on 2026-10-17 found that some historical “completed” conclusions exceeded what the code and tests actually cover; the summary claim that “only two environment walkthroughs remain” is no longer usable.

- Architecture and TODO review: code evidence, six gaps, the new requirement model, and re-acceptance conditions.
- Meshlet / ZeroTier / Tailscale personal-networking research: a 61-item feature comparison, official sources, personal necessity, implementation difficulty, and test plans.
- Modularity and library-reuse proposal: dependency boundaries, shared libraries, and incremental migration; a conventional virtual NIC remains the primary path, with NIC-less service entry points assessed as needed.
- Gateways, network conflicts, and port forwarding: selecting a gateway per segment, Alias conflict domains, and complete scenarios and acceptance for an A-side port reaching a B-side service.
- Segment-as-trust-group design: ADR-012 adopts Segments within a Network, same-segment trust, default deny across segments, and unidirectional authorization contracts; IM-01 model fields and compile wiring, IM-02 default-segment creation/persistence, and IM-03 model and startup-recovery boundary validation are complete; kernel policy enforcement is still accepted by PN-02.
