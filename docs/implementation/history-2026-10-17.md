# Implementation History Through 2026-10-17

This page is a dated record of project phases and accepted changes. It preserves historical context; current feature status belongs in the active TODO and current tests.

## Architecture and prototype

The project began by defining a self-hosted private-network product, choosing a hub-relay topology, and documenting domain entities and operating-system boundaries. Architecture reviews compared proposed behavior with the code and narrowed the first release to a manageable Overlay and management plane.

## Core Overlay and console

The server gained network and device entities, IPv4 allocation, enrollment, persistence, authentication, and a web console. Configuration revisions separated recorded intent from successful application.

## LAN routes and Alias mappings

Later phases added gateway-published LAN routes and virtual Alias prefixes for overlapping networks. These features require explicit return-path choices, conflict checks, and attributable NAT rules.

## Reliability and operations

Subsequent work added diagnostics, audit events, backups, restore, restart reconstruction, agent reconciliation, and hosted nightly builds. Each area has separate tests and operational limits.

## External control and enrollment

Scoped API tokens support external callers. Bootstrap registration creates a pending request that an operator approves before the device receives an address and desired configuration.

## Reading this record

Historical checkbox states and test counts are snapshots. Use the active architecture decisions and TODO for present behavior. The record does not claim Windows completeness, mobile support, production deployment, or any data-plane behavior beyond its stated evidence.
